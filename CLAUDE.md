# Claude entry point

Before working on PackPilot, read [AGENTS.md](AGENTS.md) and [COLLABORATION.md](COLLABORATION.md). Follow the same project, calculation, security and collaboration rules as Codex. For backend work, also read [backend/AGENTS.md](backend/AGENTS.md).

Use `COLLABORATION.md` as the shared handoff document; do not maintain a competing status board here. Fetch current repository state and inspect open PRs before starting. Work in your own task branch and report the exact commit, validation results and next step when handing work back.
